# Flujo de Pago a Proveedor — Comparativo de Canales (Cálidda Hogar)

> Nota interna: describe el proceso operativo desde la venta hasta el abono en cuenta del proveedor. Es información de referencia interna; el ciclo de pago es el mismo para ambos canales.

Actores: Cálidda, Instalador / Alo Cálidda, Proveedor, Proceso de Pagos (Finanzas Cálidda).

## Canal Alo Cálidda (cliente habilitado) — 10 pasos
1. Venta a cliente habilitado — Cálidda realiza la venta del gasodoméstico al cliente ya habilitado.
2. Pedido SAP / Generación del GSD — Se registra el pedido en SAP y se genera automáticamente la Orden de Trabajo (OT).
3. Entrega e instalación — El proveedor entrega e instala el gasodoméstico en el domicilio del cliente.
4. Presentación de sustentos — El proveedor reúne y carga todos los sustentos de la entrega.
5. Notificación de OT SAP — El proveedor notifica la OT a Cálidda indicando que la entrega está documentada.
6. Validación de sustentos — Cálidda revisa que los sustentos estén completos y conformes.
7. Aprobación para pago — Si todo está conforme, se aprueba la OT para pago.
8. Envío de data para pago (jueves) — Se envía la data al proceso de pagos todos los jueves.
9. Registro en sistema (hasta martes) / Abono al proveedor (viernes) — Las OT aprobadas se consolidan y registran; Finanzas registra y procesa las órdenes aprobadas en sistema hasta el martes siguiente.
10. Abono al proveedor — El abono se realiza el viernes de esa misma semana.

Tiempo estimado desde aprobación hasta abono: **8 a 9 días calendario aprox.** (Envío de data jueves → Registro hasta martes → Abono viernes)

## Canal Instalador Aliado — 11 pasos
1. Venta y financiamiento aprobado — El instalador realiza la venta y se aprueba el financiamiento del cliente.
2. Coordinación de fecha de habilitación — Cálidda coordina con el instalador la fecha de habilitación del servicio.
3. Pedido SAP / Generación de Orden de Trabajo — Se registra el pedido en SAP y se genera automáticamente la OT.
4. Habilitación del servicio — Cálidda habilita el servicio en la fecha coordinada.
5. Entrega e instalación del GSD — El proveedor entrega e instala el gasodoméstico en el domicilio del cliente.
6. Presentación de sustentos — El proveedor reúne y carga todos los sustentos de la entrega.
7. Notificación de OT SAP — El proveedor notifica la OT a Cálidda indicando que la entrega está documentada.
8. Validación de sustentos — Cálidda revisa que los sustentos estén completos y conformes.
9. Aprobación para pago — Si todo está conforme, se aprueba la OT para pago.
10. Envío de data para pago (jueves) — Se envía la data al proceso de pagos todos los jueves.
11. Registro en sistema (hasta martes) / Abono al proveedor (viernes) — Las OT aprobadas se consolidan y registran; Finanzas registra y procesa las órdenes aprobadas en sistema hasta el martes siguiente, con abono el viernes de esa misma semana.

Tiempo estimado desde aprobación hasta abono: **8 a 9 días calendario aprox.** (mismo ciclo semanal: envío jueves → registro hasta martes → abono viernes)

## Documentación / sustentos requeridos (ambos canales)
- Boleta de venta.
- Guía de remisión.
- Fotos de instalación (GSD, cliente, DNI).
- Certificado de garantía.
- Acta de conformidad de entrega.
- Carta poder (si aplica).

## Puntos clave para el proveedor
- La Orden de Trabajo (OT) se genera automáticamente al crear el pedido en SAP.
- El proveedor debe entregar, documentar y notificar la OT SAP para que su proceso de pago inicie.
- El pago no es inmediato: se sigue el ciclo semanal de pagos (envío jueves, registro hasta martes y abono viernes).
- La documentación completa y legible evita observaciones y retrasos.
